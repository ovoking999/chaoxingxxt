# 学习通发送到github

学习通 7.0.6 + 学习助手（KSN 注入引擎）安装包仓库。

## 包内容

| 文件 | 说明 |
|---|---|
| `学习通发送到github.apk` | 学习通 7.0.6 + 学习助手（com.chaoxing.mobile, versionCode 10997） |

内置功能（学习助手）：

- 自动答题：单选 / 多选 / 填空 / 简答（多选全套、简答 autofill）
- 签到：真实定位签到（学习通原生定位，定位失败自动兜底）
- 答题截图 / OCR 识别链路
- 卡密制：云端激活，日卡 / 年卡（会员期内不清零，免每日领取）
- 考试高版本伪装、答题截屏预设（默认关闭，仅配置项保留）

## 安装

1. 先**卸载**旧版（签名不同，不能直接覆盖）
2. 安装 `学习通发送到github.apk`
3. 打开学习通 → 进入「学习助手」入口 → 输入卡密激活

> 360 加固壳版本（若发布）签名与直签版不同，同样需要先卸载再装。

## 常见问题

- **打开后黑屏**：部分 vivo 机型（secure 通道）偶发黑屏，重进或换可截图版。
- **闪退**：卸载重装；仍闪退检查系统版本与内存。
- **删除重装**：仅记录，不影响领取与激活。
- **卡密**：请勿分享，同卡多设备使用会自动吊销。
