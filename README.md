# 📚 学习通学习助手（Study Companion）

> 学习通 7.0.6 学习辅助工具 · 自动作业 / 签到 / 答疑 一站式

面向超星学习通（com.chaoxing.mobile 7.0.6）的学习辅助应用：进入「学习助手」入口后，可自动完成日常作业题目、签到打卡，并对填空题提供答案辅助。

---

## ✨ 功能特性

| 模块 | 说明 |
|---|---|
| 🎯 自动答题 | 单选 / 多选 / 判断 / 连线题自动作答（事件驱动，逐题核对不跳题） |
| ✏️ 填空 / 简答辅助 | AI 计算答案并自动放入剪贴板，点答题框长按粘贴即可（2 秒完成） |
| ✅ 签到 | 真实定位签到（定位失败自动兜底，不挂签） |
| 🔔 推送提醒 | 作业 / 活动提醒，后台保活不掉线 |
| 🎫 卡密制 | 每日免费领取卡 / 年卡（会员期内不清零、免每日领取），云端同步 |
| ⚡ 低耗设计 | 空闲自动休眠，答题时唤醒；不影响学习通其他功能 |

## 📦 下载安装

1. 在 [Releases](https://github.com/ovoking999/chaoxingxxt/releases) 页下载 `study-assistant-v12.apk`（约 350 MB）
2. **先卸载旧版**（不同版本签名互不兼容，直接覆盖会失败）
3. 安装下载的 apk
4. 打开学习通 → 底部「学习助手」入口 → 输入卡密激活
5. 配置模型端点后开始使用

> ⚠️ 安装前请允许「安装未知来源应用」。

## 🚀 快速上手

1. **领卡**：群内公告 / 卡密页领取每日卡（免费，绑定单设备）
2. **配置**：学习助手设置 → 填写模型端点与 Key（群内提供）
3. **开始**：进入作业页 → 自动答题开关打开 → 题目逐题自动完成
4. **填空题**：看到通知「答案已放入剪贴板」→ 点答题框 → 长按粘贴 → 下一题

## ❓ FAQ

**Q：打开后黑屏？**
个别机型（部分 vivo）系统对安全窗口渲染异常。重进一次；仍黑屏请群里反馈机型。

**Q：闪退 / 卡死？**
强制停止学习通后重进。答题中途卡死时答案仍在剪贴板，重进后可继续粘贴。

**Q：删除重装后卡密失效？**
不会。卡密绑定设备（非包数据），重装后自动恢复；云同步异常时杀 App 重进一次即可。

**Q：填空题为什么要点一下？**
学习通填空题编辑器需要真人手势激活，工具自动算好答案放剪贴板，手动粘贴 2 秒。

**Q：更新版本？**
群内发新版包；先卸载旧版再装。
